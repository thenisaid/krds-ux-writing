# B2G UX Writing 서비스 패키지

> KRDS 기반 정부기관 UX Writing 전문 서비스 상품화 문서

---

## 파일 목록

| 파일 | 내용 |
|------|------|
| `01-service-lineup-pricing.md` | 서비스 라인업 정의 + 기관 규모별 가격표 + 조달 정보 |
| `02-government-proposal-template.md` | 나라장터 규격 준수 제안서 템플릿 (전체 구조) |
| `03-sow-templates.md` | 계약 유형별 SOW 템플릿 (A~E 5종) |

---

## 서비스 유형 요약

| 서비스 | 유형 | 납기 |
|--------|------|------|
| A. UX Writing 감사 | 단기 프로젝트 | 4~8주 |
| B. 가이드라인 납품 | 프로젝트 | 8~12주 |
| C. 서비스 문구 개편 | 프로젝트 | 12~20주 |
| D. 교육·훈련 워크숍 | 교육 사업 | 1~3일 |
| E. 운영 위탁 | 연간 유지보수 | 1년+ |

---

## 사용 방법

1. **제안서 작성**: `02-government-proposal-template.md` 를 기반으로 `[ ]` 항목 작성
2. **SOW 선택**: 계약 유형에 맞는 SOW (A~E) 선택 후 상세 조건 조정
3. **가격 산정**: `01-service-lineup-pricing.md` 참조하여 기관 규모에 맞는 단가 적용
4. **번들 할인**: 2개 이상 서비스 결합 시 할인율 적용 가능
