# B2G UX Writing 서비스 패키지 정의 및 가격표

> 버전: 1.0 | 작성일: 2026-04-18 | 작성: UX Writer (KRDS 기반 공공 UX Writing 전문)

---

## 1. 서비스 철학

정부 디지털 서비스의 UX Writing은 단순한 카피라이팅이 아닙니다.
**행정 언어 → 시민 언어** 전환을 통해 국민의 인지 부하를 줄이고, 서비스 목적 달성률을 높이는 **시스템적 텍스트 설계**입니다.

- KRDS(Korea Design System) 컴포넌트 기반 마이크로카피 작성
- KWCAG 2.1 접근성 기준 준수 (텍스트 가독성, 오류 메시지, 폼 레이블)
- 나라장터 조달 규격 호환 납품 가능

---

## 2. 서비스 라인업

### 서비스 A — UX Writing 감사 (Audit)
**계약 형태**: 단기 프로젝트 | **납기**: 4~8주

| 항목 | 내용 |
|------|------|
| 목적 | 기관 웹·앱 서비스 전체 문구 진단 및 개선 리포트 납품 |
| 산출물 | 감사 리포트 (문제 현황 + 우선순위 개선안), 개선 문구 초안 |
| 범위 | 메인~3depth 페이지, 오류·알림·온보딩 문구 포함 |
| 기준 | KRDS 가이드라인, 쉬운 정부 언어 기준, KWCAG 2.1 |

---

### 서비스 B — 기관별 UX Writing 가이드라인 납품
**계약 형태**: 프로젝트 | **납기**: 8~12주

| 항목 | 내용 |
|------|------|
| 목적 | 기관 맞춤형 UX Writing 가이드라인 문서 수립 및 납품 |
| 산출물 | 가이드라인 문서 (PDF + 편집 가능 파일), 컴포넌트별 마이크로카피 예시집 |
| 범위 | 보이스 앤 톤 정의, 버튼·폼·알림·오류 메시지 작성 규칙 |
| 특이사항 | 담당 공무원 교육 세션 1회 포함 |

---

### 서비스 C — 서비스 문구 전면 개편
**계약 형태**: 프로젝트 | **납기**: 12~20주

| 항목 | 내용 |
|------|------|
| 목적 | 기관 디지털 서비스 전체 마이크로카피 재작성 |
| 산출물 | 전체 문구 수정본 (스프레드시트 + KRDS 컴포넌트 매핑), QA 체크리스트 |
| 범위 | 웹/앱 전체 화면 (버튼, 레이블, 안내문, 에러, 알림, 온보딩) |
| 협업 | 기관 UI 디자이너·개발자 협업 필수 (킥오프 미팅 포함) |

---

### 서비스 D — 교육·훈련 워크숍
**계약 형태**: 교육 사업 | **납기**: 1일~3일 집중 과정

| 항목 | 내용 |
|------|------|
| 목적 | 공무원 대상 UX Writing 역량 강화 교육 |
| 산출물 | 교육 자료 (슬라이드 + 실습 워크북), 수료증 |
| 과정 | 기초 과정 (4H) / 심화 과정 (8H) / 실무 프로젝트 과정 (3일) |
| 인원 | 회당 최대 30명 |

---

### 서비스 E — 운영 위탁 (유지보수 계약)
**계약 형태**: 연간 유지보수 | **계약 기간**: 1년 (갱신 가능)

| 항목 | 내용 |
|------|------|
| 목적 | 서비스 개편·신규 기능 출시 시 지속적 UX Writing 지원 |
| 산출물 | 월간 문구 업데이트, 분기별 가이드라인 리뷰, 긴급 문구 수정 대응 |
| SLA | 긴급 요청 24H 이내 초안 제공, 일반 요청 5영업일 이내 |
| 포함 | 연 2회 감사 리뷰 포함 |

## 4. 패키지 번들 할인

| 번들 조합 | 할인율 | 비고 |
|-----------|--------|------|
| A + B (감사 → 가이드라인) | 10% 할인 | 가장 일반적인 진입 패턴 |
| A + C (감사 → 개편) | 15% 할인 | 리포트 기반 즉시 개편 |
| B + E (가이드라인 + 유지보수) | 12% 할인 | 지속적 관리 계약 |
| A + B + E (풀 패키지) | 20% 할인 | 장기 파트너십 권장 |
