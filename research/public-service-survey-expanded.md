# Expanded Public Service Survey

> 갱신일: 2026-06-14
> 목적: `research/public-service-corpus.md`의 대표 코퍼스를 넘어, 국민이 자주 쓰는 공공서비스 사이트를 넓게 식별하고 저장소 반영 상태를 분류한다.
> 상태: 3차 확장 인벤토리. **공공기관 전체 페이지 전수조사 완료 문서가 아니다.**

## 1. 조사 단위

이 저장소의 조사 단위는 `사이트 전체 크롤링`이 아니라 `과업 단계별 대표 화면 샘플링`이다.
따라서 아래 목록은 "다음 라운드에 포함할 사이트 인벤토리"이며, "공공기관 전체 페이지를 다 확인했다"는 뜻이 아니다.

- 사이트 단위: 시민 대상 공공서비스, 반복 이용, 로그인·신청·조회·납부·발급·신고가 있는 서비스
- 화면 단위: 검색, 자격/조건, 입력/첨부, 오류/실패, 완료/결과, 처리 상태, 법적 고지
- 포함 우선: 생활 밀착도, 실수 비용, 반복 이용 빈도, 서류·기한·상태 확인 비중이 큰 서비스
- 제외: 내부 행정시스템, 공급자 전용 백오피스, 일회성 이벤트 페이지

대표 과업은 2026-06-11~2026-06-14 기준 각 서비스의 공식 메인화면, 사이트맵, 이용안내에서 바로 드러나는 메뉴·설명만 적었다.
세부 법령 분기나 예외 규정까지는 아직 페이지 샘플링 전 단계다.

## 2. 범위 기준선

외부 공공서비스 조사는 "국민이 많이 쓰는 대표 포털"을 먼저 좁혀도 범위가 크다.
2026-06-11 기준으로 확인한 공식 범위 기준선은 아래와 같다.

| 공식 기준선 | 확인한 내용 | 조사에 주는 뜻 |
|------------|-----------|---------------|
| 정부24 `정부/지자체 누리집` | 누리집 925건, 모바일앱 193건 | 정부·지자체 공식 채널 전체를 문자 그대로 다 보는 방식은 별도 장기 과제다. |
| 잡알리오 `공공기관 정보` | 2026년 공공기관 342개 | 기관 단위 전수와 시민용 서비스 포털 전수는 다른 작업이다. |

따라서 이 문서는 `공공기관 전체 웹사이트 목록`이 아니라,
그 안에서 **시민이 실제 과업을 수행하는 공공서비스 포털의 작업용 인벤토리**를 만드는 문서로 관리한다.

### 3.2 상태 판정 규칙

이 문서에서 상태는 아래 기준으로 나눈다.

- `핵심 코퍼스`: `research/public-service-corpus.md`에 대표 사이트로 고정돼 있고, 원칙·사전·사례 카드에 반복 근거가 연결된 상태
- `간접 반영`: 다른 대표 사이트 맥락 안에서 외부 포털의 과업 또는 명칭이 반복적으로 직접 언급된 상태
- `미반영`: 기관명이나 외부 다음 단계가 산발적으로 스쳐 지나갈 수는 있어도, **그 포털 자체를 독립 사이트 단위로 조사한 로그가 없는 상태**

예를 들어 `병무청`, `한국장학재단`, `재외국민 등록`은 일부 `derived/jeongbu24-guide.md` 문제 진술 안에 등장하지만,
이 문서 기준으로는 아직 `포털 독립 조사`가 없으므로 `미반영`으로 둔다.
