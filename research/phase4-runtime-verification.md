```md
# 서울시립미술관 (SeMA) Layer 3 파생 가이드 초안

## 1. 이 기관의 주요 UX Writing 과제
서울시립미술관의 주요 서비스 흐름은 전시 탐색, 전시 예약, 교육 프로그램 신청 등이 포함됩니다. 각 서비스에 대한 명확하고 접근 가능한 언어 사용이 중요합니다.

## 2. 기관 핵심 서비스 흐름
- **전시 탐색**: 관람객이 다양한 전시를 쉽게 찾을 수 있도록 정보 제공
- **전시 예약**: 관람객이 전시 관람을 위한 예약 과정을 원활하게 진행할 수 있도록 안내
- **교육 프로그램 신청**: 교육 프로그램 참여를 위한 신청 과정 안내

## 3. 전문용어 추가 사전
| 원어 | 대체어 | 맥락 | 허용 예외 |
|---|---|---|---|
| 전시 예약 | 전시 관람 예약 | 관람객이 전시를 보기 위해 시간을 예약할 때 | - |
| 도슨트 | 전시 안내자 | 전시에 대한 설명을 담당하는 전문가 | - |
| 교육 프로그램 | 교육 강좌 | 관람객을 위한 특별한 교육 활동 | - |
| 관람권 | 티켓 | 전시 관람을 위한 입장증 | - |
| 접수 | 신청 | 프로그램이나 서비스에 대한 신청 과정 | - |

## 4. 주요 오류 시나리오 5개
1. **전시 탐색 오류**
   - **상황**: 사용자가 검색한 전시가 존재하지 않음.
   - **이유**: 정확한 전시명이나 기간을 입력하지 않았을 수 있음.
   - **다음 행동**: 다른 전시명이나 기간으로 검색해 보세요.
```
