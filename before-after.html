원칙 Before / After

무번역·정보핵심화·심리적안전망 — 3대 원칙이 실제 공공 서비스 텍스트에 어떻게 적용되는지 전/후 비교로 확인하세요.

원칙 A — 무번역

행정어·한자어를 국민의 언어로

공공기관이 오랫동안 사용해온 행정 관습어와 한자어를 풀어 씁니다. 번역 없이 바로 이해할 수 있어야 합니다.

신청 완료 알림

✗ Before

귀하의 신청이 접수되었습니다. 결과는 익일까지 안내해 드리겠습니다.

✓ After

신청이 완료되었습니다. 결과는 내일까지 알려드리겠습니다.

방문 안내

✗ Before

교부 신청서를 지참하여 직접 내방하여 주시기 바랍니다.

✓ After

발급 신청서를 들고 직접 방문해 주세요.

보호자 동의 안내

✗ Before

법정대리인의 인감 날인이 필요합니다.

✓ After

부모님 또는 후견인의 도장이 필요합니다.

처리 결과 안내

✗ Before

피부양자 등재 신청이 접수되었습니다. 상기 사항을 확인하여 주시기 바랍니다.

✓ After

부양가족 등재 신청이 완료되었습니다. 위 내용을 확인해 주세요.

원칙 B — 정보핵심화

필요한 정보만, 가장 짧게

읽는 사람이 결정을 내리거나 행동을 취하는 데 필요한 정보만 담습니다. 한 문장에 한 가지 메시지를 전합니다.

오류 안내 문구

✗ Before

서비스 이용 중 불편함이 있으시거나 오류가 발생하였을 경우, 저희 고객센터(1234-5678)로 연락 주시면 신속하게 처리해 드리도록 하겠습니다.

✓ After

오류가 발생했나요? 고객센터 1234-5678

파일 업로드 안내

✗ Before

첨부파일은 PDF, JPG, PNG 형식의 파일만 업로드 가능하며, 파일의 크기는 최대 10MB까지만 가능합니다. 그 외의 파일 형식이나 10MB를 초과하는 파일은 업로드가 되지 않습니다.

✓ After

첨부파일: PDF · JPG · PNG, 최대 10MB

버튼 레이블

✗ Before

클릭하시면 신청이 완료되고 신청 내역 확인 페이지로 이동하게 됩니다

✓ After

신청하기

공지 제목

✗ Before

2026년도 제1차 국민 참여 정책 제안 공모전 시행 계획 공고에 대한 안내

✓ After

2026 정책 제안 공모전 안내

원칙 C — 심리적안전망

비난 대신 해결책, 불안 대신 안심

실수한 사용자를 탓하지 않습니다. 무엇을 해야 하는지 알려주고, 다음 단계로 나아갈 수 있도록 돕습니다.

로그인 오류 메시지

✗ Before

비밀번호가 틀렸습니다. 다시 입력하세요.

✓ After

비밀번호가 일치하지 않습니다. 다시 확인해 주세요.

입력 오류 메시지

✗ Before

잘못 입력하셨습니다. 올바른 정보를 입력해 주세요.

✓ After

확인이 필요한 항목이 있습니다. 이름과 생년월일을 다시 입력해 주세요.

파일 업로드 오류

✗ Before

파일 업로드에 실패했습니다. 오류 코드: ERR_403

✓ After

파일을 업로드하지 못했습니다. 파일 크기가 10MB 이하인지 확인하고 다시 시도해 주세요.

마감 안내 문구

✗ Before

기한 내 미신청 시 불이익이 발생할 수 있습니다.

✓ After

3월 31일까지 신청하시면 혜택을 받으실 수 있습니다.

직접 실험
